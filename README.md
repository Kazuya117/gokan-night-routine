# 五感ナイトルーティン

五感を使って寝る前のスマホを手放し、睡眠の質を上げるためのWebアプリ（PWA）です。
三田国際科学学園 リベラルアーツのテーマ「五感を利用したスマホ脱却と睡眠の質の改善」のための試作版です。

## できること

| 画面 | 内容 |
|---|---|
| 今夜 | 使う感覚（聴覚・触覚・視覚・嗅覚・味覚）、音、長さを選んで「おやすみモード」を開始 |
| おやすみモード | 環境音（雨・波・低い音）と呼吸ガイド（4秒吸って8秒吐く）。スマホを伏せると画面が真っ暗になり、伏せ置き時間と持ち上げた回数を記録 |
| 朝チェック | 寝つき・目覚め・夜のスマホ使用を3タップで記録 |
| ふりかえり | 連続達成日数、感覚べつの睡眠スコア、直近14日のグラフ、CSV書き出し |

## 動かし方

ビルドは不要です。フォルダをそのまま静的サイトとして配信します。

```bash
npx serve .        # または python3 -m http.server
```

GitHub Pages で公開すれば、生徒はURLを開いて「ホーム画面に追加」するだけで使えます。

## 仕様メモ

- 記録は端末内（localStorage）だけに保存し、サーバーには送りません。
- 「夜」の日付は、正午より前なら前日の夜として扱います。
- 睡眠スコア＝寝つき(1〜5)＋目覚め(1〜5)の10点満点。
- 連続達成＝「布団に入ってからスマホを触らなかった」夜が続いた日数。
- 視覚を選ぶと、おやすみモードが暖色の灯りで始まり、3分かけて暗くなります。Webアプリから端末の画面輝度そのものは変えられないため、画面の色と明るさで表現しています。
- おやすみモード中は画面を点けたまま（ほぼ真っ黒）にします。画面が消えるとブラウザのタイマーと音が止まるためです。
- 触覚の呼吸ガイドは、Android（Chrome）では振動、iPhoneでは音で行います。iPhoneのブラウザには振動させる機能がないためです。
- Androidで振動しない場合は、マナーモード・おやすみモード・省電力モードと、本体設定の「バイブレーション／触覚フィードバック」を確認してください。
- 伏せ置き検知は傾きセンサーを使います。iPhoneでは開始時に許可を求められます。

## 更新するとき

`app.js` の `VERSION`、`index.html` の `?v=`、`sw.js` の `CACHE` と `?v=` の数字を同じ値に上げてください。利用者の端末に新しい版が確実に届きます。現在の版は「ふりかえり」画面の下部に表示されます。

## まだないもの

- 就寝前の通知（Webアプリでは制約が多いため、まずは端末のアラームで代用）
- チームチャレンジ（サーバーが必要）
- 他アプリのブロック、スクリーンタイムの自動取得（Webアプリでは不可）
